# **App Name**: Ashground

## Core Features:

- Header Display: Display a header with the app name "ASHGROUND" in a large, elegant serif font and the tagline "By Asto Eterna" in a smaller italic font.
- Tabbed Toolbar: Render a horizontal toolbar with frosted glass tab buttons for "Home", "Draw", "View", and "Export".
- Paper-like Page Area: Create a centered "page" area with rounded corners, a subtle shadow, and a light paper texture background for the note.
- Note Title: Fixed "Untitled Note" title in the top left corner of the page, using an elegant serif font.
- Writing Area: Provide a writing area with a modern sans-serif font and comfortable line spacing.
- Home Tab Tools: Display visual placeholders for text formatting tools (Bold, Italic, Underline, Bullet list, Text alignment) within the "Home" tab.
- Drawing Tools: Implement drawing tools (Pen, Brush Size, Eraser, Undo) in the "Draw" tab.
- Page Background Selection: Add options to select a page background style: plain, lined, or grid paper in the "View" tab.
- Theme Presets: Provide Theme presets in the view tab: light, dark, and pastel themes to change the page colors
- Export Tools: Implement the Export tab, which provides options for text download and copying to clipboard

## Style Guidelines:

- The overall color scheme should evoke feelings of gentle warmth and understated quality. Primary color: Off-white (#F8F5F0), to suggest aged parchment.
- Background color: Very light desaturated yellow (#F9F6EF), implemented as a gradient.
- Accent color: Light desaturated violet (#E6D9EB), applied selectively to interactive elements.
- Headline font: 'Playfair' (serif) for the product name and note title, evoking feelings of quality.
- Body font: 'PT Sans' (sans-serif) for the writing area, creating a modern, neutral, easily legible style.
- Use minimalist icons for toolbar buttons and tools.
- Center the layout horizontally, with margins on large screens.
- Use subtle animations for hover effects and tab transitions.
